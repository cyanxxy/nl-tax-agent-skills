## Phase 8 — Missing information

### 8.1 Collect all gaps

Review every section for data gaps:
- Income sources without a document or chat value
- Asset values without bank statements or a stated figure
- Deduction claims without receipts
- Screening facts that were assumed rather than confirmed
- Every row still marked `Src: ?`

### 8.2 Record missing information

Record each gap in the workpack's `## Missing information` section as an M-ID
(`M001`, `M002`, ...; never renumber):
- Each item has a priority: critical (blocks filing), important (affects accuracy), nice-to-have
- Each item names the workpack row it affects and links the open Q-ID when one exists
- Each item describes what is needed and where the taxpayer can obtain it

Remove an item once its value is recorded with provenance. When the workpack
is saved, the section is updated in the file at the end of the turn.
