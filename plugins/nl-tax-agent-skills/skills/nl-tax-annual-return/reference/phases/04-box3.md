## Phase 4 — Box 3 compilation

Compile savings and investment data for box 3. BOTH methods must be covered. Read the rates from `_shared/knowledge/years/2025/box3/fictitious.md` — never paraphrase from memory.

### 4.1 Assets on peildatum 1 January 2025

Collect values for each asset category:

#### Banktegoeden (category I)
- All savings accounts, current accounts, deposits, term deposits
- Cash only above the 2025 cash exemption, non-exempt green savings, premiedepots, VvE reserve shares, and money on notary/bailiff third-party accounts where applicable
- Source: bank statements or jaaropgaven with balance on 1 January 2025
- Match against evidence index items classified as bankafschrift or jaaropgaaf-bank

#### Overige bezittingen (category II)
- Investment portfolios (listed securities, mutual funds)
- Crypto-assets (valued at market price on 1 January 2025)
- Real estate not being the eigen woning (second homes, rental property)
- Receivables (vorderingen) -- loans to others, after checking official exceptions
- Other assets
- Source: portfolio year-end statements, crypto exchange statements

#### Schulden (category III)
- Screen each debt against the official 2025 Box 3 included/excluded lists;
  never classify it merely because it is not an own-home mortgage.
- Consumer loans, qualifying study-finance debts, negative bank balances,
  financing for Box 3 assets, repayable benefits, and inheritance tax are
  examples that may qualify. Own-home and business debts, most Dutch tax debts,
  short current liabilities, certain maintenance/inheritance obligations, and
  debts connected with Box 2 or other work are examples that do not.
- Keep unresolved classifications outside trusted totals, ask one focused
  follow-up, and require manual portal review if still unresolved. Apply the
  debt threshold only to the qualifying Box 3 debt total.

### 4.2 Year-end values only where value changes count

- Do not collect a blanket 31 December balance for every Box 3 category.
- For ordinary savings, current, and deposit accounts, collect the 1 January
  2025 balance for the fictitious method and actual interest received during
  2025 for the optional actual-return comparison. Do **not** ask for a 31
  December bank balance merely because the taxpayer chose that comparison.
- For investments, securities, crypto-assets, second homes, other Box 3 real
  estate, and other assets whose value change counts, collect the start-of-year
  or acquisition value plus the 31 December value or disposal proceeds/date as
  applicable.
- For qualifying Box 3 debts, collect the 1 January amount for the fictitious
  method and interest paid during 2025 for actual return. Do not request a
  blanket 31 December debt balance unless a named applicable rule requires it.

### 4.3 Fictitious return calculation

Follow the calculation method from `fictitious.md`:
1. Calculate aftrekbare schulden after the debt threshold
2. Calculate belastbaar rendement by category
3. Calculate rendementsgrondslag
4. Calculate grondslag sparen en beleggen after heffingsvrij vermogen
5. Calculate aandeel in de rendementsgrondslag
6. Calculate box 3 income and box 3 tax

Common failure: do NOT apply heffingsvrij vermogen before calculating belastbaar rendement.

### 4.4 Actual return data collection

Always explain the actual return (werkelijk rendement) alongside the fictitious
(forfaitair) calculation. The taxpayer decides whether to provide the additional
actual-return data when the portal offers that question; this is a data-supply
decision, not an election to make the higher-tax method apply. If the data is
provided, the official 2025 return calculates both and uses the more favorable
amount. The actual-return subsection is never silently omitted.

Follow the data requirements from `actual-return.md`:
1. Actual interest received on bank accounts during 2025
2. Dividends received (before dividend withholding tax)
3. Bare rental income (kale huur) and other income from box 3 assets
4. Value changes for disposed box 3 assets, including sale proceeds and start-of-year or acquisition values
5. Value changes for retained or acquired box 3 assets, including investments, securities, crypto-assets, second homes, other box 3 real estate, and other assets where value changes count
6. Interest paid on box 3 debts
7. Qualifying WOZ-value investment correction data, if applicable

Do not deduct custody fees, transaction costs, management fees, maintenance costs, or adviser fees from actual return.

Do not deduct heffingsvrij vermogen from actual return. If fiscal partners choose a box 3 allocation, apply the same allocation percentage to actual return for the comparison.

If the taxpayer provides every required input, compare both calculations regardless
of whether provenance is indexed files, chat, or a mixture. Mark the subsection
`chat_only` when the complete input set is chat-supplied, otherwise `complete`,
and cross-index every chat value. If the taxpayer explicitly declines, mark the
subsection `complete` with an answered `not supplied by choice`; this is neither
a gap nor a deferred section and does not block a complete workpack. Only facts
still missing after the taxpayer chose the comparison become `deferred/manual
review`. Do not claim that both calculations were completed unless both were.

### 4.5 Comparison: fictitious vs actual

- When actual-return inputs were supplied, present both calculations side by
  side and note which method results in lower box 3 tax
- When the taxpayer declined to provide the additional data, state that no
  comparison was prepared and retain the completed fictitious-return estimate.
- State that the portal performs the authoritative comparison and uses the
  favorable amount when actual-return data is supplied. The workpack neither
  chooses a tax method nor promises the portal result.

### 4.6 Partner allocation for box 3

- If fiscal partners: the joint grondslag sparen en beleggen can be freely allocated (0%-100%)
- The allocation applies to the entire joint box 3 base, not individual assets or debts
- Both partners must use the same allocation ratio
- Present simple scenarios such as 50/50, 100/0, and 0/100; do not select a binding allocation automatically
