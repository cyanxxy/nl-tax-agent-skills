**CRITICAL: This reference is ONLY for the annual 2025 path. It must NEVER be used for provisional 2026.**

## Background

For the 2025 return, taxpayers may choose whether to supply complete
actual-return data. When they do, Mijn Belastingdienst calculates the actual
and fictitious outcomes and uses the more favorable amount. Supplying the data
is not an election to make a higher-tax method binding; this is a data-supply
choice, not a tax-method election.

Actual return is calculated without applying heffingsvrij vermogen. For fiscal partners, the actual return is divided using the same allocation chosen for the joint grondslag sparen en beleggen.

## What Counts as Actual Return

### Included
- Interest received (rente-inkomsten)
- Dividends received (dividend)
- Rental income from box 3 property (huurinkomsten)
- Value changes of box 3 assets during 2025, including investments, securities, crypto-assets, second homes, other box 3 real estate, and assets acquired or disposed of during the year
- Interest paid on box 3 debts, as a permitted negative component

For ordinary savings, current, and deposit accounts, ask for actual interest
received during 2025, not a 31 December bank balance. Year-end values belong
only to investments, securities, crypto-assets, real estate, and other assets
whose value changes count.

### Excluded
- Value changes in own home (waardeverandering eigen woning)
- Exempt pension rights and box 1 annuity rights. Non-exempt periodic-payment rights, net annuities, and net pensions may belong in box 3 and require manual review.
- Exempt life-insurance values, including qualifying own-home capital insurance. Non-exempt capital insurance values can belong in box 3.

## Costs

Costs may not be deducted from actual return, except for the official exceptions below.

### NOT Deductible
- Custody fees (bewaarloon)
- Management fees (beheerkosten)
- Transaction costs
- Maintenance costs
- Bank fees for payment accounts (bankkosten betaalrekening)
- Financial adviser fees

### Permitted Exceptions
- Interest paid on box 3 debts
- Qualifying WOZ-value investment correction under the official conditions

## Comparison Method

1. Calculate the fictitious return using the official Belastingdienst step model
2. Calculate the actual return using the rules above, without deducting heffingsvrij vermogen
3. Present both side by side
4. Note which outcome appears lower as an informational cross-check
5. The official filing environment performs the binding comparison and uses
   the favorable amount — the workpack provides notes only

## Applicability Constraint

This reference applies exclusively to the **annual 2025 return**. For the provisional 2026 assessment (voorlopige aanslag 2026), only the fictitious return method is available. Do not apply actual return logic to provisional assessments.
