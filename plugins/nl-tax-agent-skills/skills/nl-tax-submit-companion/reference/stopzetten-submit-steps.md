# Manual Steps -- Stopping a Voorlopige Aanslag (Stopzetten)

## Steps

1. Go to Mijn Belastingdienst (mijn.belastingdienst.nl)
2. Log in with DigiD
3. Navigate to voorlopige aanslag 2026
4. Select the option to stop (stopzetten)
5. Confirm that you want to stop the monthly refund
6. Monthly refunds will stop
7. Final settlement happens at annual return time

## Note

Stopzetten is for taxpayers who receive a monthly refund. If you currently pay monthly and want a different amount, use the CHANGE (wijzigen) process instead of stopzetten. Changing allows the provisional assessment to be recalculated from current estimates.
