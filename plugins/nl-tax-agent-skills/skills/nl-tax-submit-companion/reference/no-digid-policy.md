# DigiD Policy -- Submission Companion

## Core policy

- This skill does **NOT** collect, store, or use DigiD credentials.
- Online Mijn Belastingdienst requires the user's own DigiD, or an authorized helper using the official DigiD Machtigen route.
- The workpack and field map are designed for **MANUAL** entry in the official online Mijn Belastingdienst portal.
- **Never** paste DigiD credentials into any file, chat, or tool.

## If you don't have DigiD

You need to apply at your municipality (gemeente). The application process takes several days as the activation code is sent by post. Plan ahead if you have an upcoming filing deadline.

## If someone helps you

They need DigiD Machtigen authorization. This is a formal process where you grant another person permission to act on your behalf through Mijn Belastingdienst. The helper uses their own DigiD after authorization; this tool never handles either person's credentials.

## Paper filing

Paper filing is outside the supported online workflow. Do not present paper filing as a supported fallback unless exact official, source-backed guidance for that taxpayer's situation has been added to the knowledge base.

## What this skill provides

This skill prepares a submission checklist and guides you through the manual steps. All actual interactions with Mijn Belastingdienst -- logging in, entering data, reviewing, signing, and submitting -- must be performed by you or your authorized DigiD Machtigen representative directly.
